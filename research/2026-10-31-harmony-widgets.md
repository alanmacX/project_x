# 鸿蒙小组件竞品与稳定性调研

日期：2026-10-31。产品代码基线：`419aa1b`。本文件记录调研结果，实施任务见 [下个 milestone](../MILESTONE_NEXT.md)。

## 调研方式和版本范围

直接使用浏览器打开华为应用市场，通过搜索框搜索“小组件”和具体应用名称，进入详情、展开 View all 阅读评价。可重复入口：[市场搜索](https://appgallery.huawei.com/search/%E5%B0%8F%E7%BB%84%E4%BB%B6)。没有下载站 APK，也没有安装或购买竞品。

读取了亿象、Top Widgets、iScreen 三个市场条目的详情及各自首屏 25 条评价，共 75 条。它们包含旧鸿蒙、Android、不同设备的用户，下面只用于发现问题，不计算鸿蒙 NEXT 用户占比或故障率。网页详情中的版本、体积、评分属于该条目；同名原生版需要单独核对。

另外阅读鸿蒙版专属帮助、开发者官网和华为官方案例。直接访问灵动小组件的精确名称搜索时，网页返回了其他相关产品；其原生功能以华为案例为依据，不能把“灵动组件盒子”“灵动万能小组件”混为同一产品。

以下是对用户反馈的概括，没有把留言中的原因归咎直接当成竞品故障根因。

| 来源 / 日期 | 用户反馈主题 | 冰箱贴的对应任务 |
| --- | --- | --- |
| 亿象市场，2026-10-13，MatePad 11.5 S [S11] | 更新系统后原布局丢失，只能参考截图重做 | 完整备份、可见恢复入口、升级前后文档和素材清单校验 |
| 亿象市场，2026-10-29 [S11] | 鸿蒙版组件较少；跨系统会员状态不同 | 维护按系统的功能清单；以后若做购买必须验证权益迁移 |
| 亿象市场，2026-08-31 [S11] | 热搜不自动更新，音乐操作跳转 App | 刷新链路与点击意图一致；外部能力不冒充本地实时能力 |
| Top Widgets，2026-09-21、10-12 [S5] | 桌面日期停在几天前；透明度编辑退化 | 跨日和后台恢复测试；历史作品视觉回归 |
| Top Widgets，2026-10-24、10-26 [S5] | 卡顿、广告打断添加 | 核心编辑和添加路径保持短；测交互延迟与投递成本 |

这些反馈支持我们优先解决保存、刷新、添加、兼容性问题。它们没有提供足够材料来判定这些竞品是否实现整库备份或崩溃恢复，所以不把这些能力写成竞品缺失。

亿象的鸿蒙帮助还记录了透明背景和桌面标题问题 [S3]。该文没有标注 API 版本；我们的 `form_config.json` 已设置 `transparencyEnabled: true`，不能直接按旧帮助关闭功能。需要保存当前系统版本和视觉样例再验收。

## 3. 我们当前代码的稳定性缺口

这次历史故障的最初触发仍没有取证到。已修复的失效 Preferences 句柄、整文件写入竞争和失败后默认空库问题，继续保留在回归门禁。新增工作应覆盖以下真实缺口：

1. **恢复入口缺失。** `LibraryBackup.readLibraryBackup` 能读取有效备份，产品入口没有使用；`library_drafts` 保存冲突改动，UI 没有取回路径。
2. **独立备份没有包含素材。** 备份 envelope 保存 `values`，图片/GIF 仍引用素材目录。需要将元数据和素材的可恢复性一起校验。
3. **分享与私人备份用途不同。** `SharedCapability` 有意移除课程、日程、倒计日等私人设置。完整恢复包应单独定义格式，不能直接复用公开分享的清洗逻辑。
4. **恢复写入协调没有实现。** 多进程连接缓存在 `LibraryStorage`；恢复时需要统一暂停写入、隔离坏库、验证新库，再开放读写和桌面刷新。
5. **保留策略按提交数，时间跨度短。** 独立备份只留 3 代，冲突草稿按 scope 留 3 份；持续编辑会很快覆盖旧时间点，不同 scope 也缺少总量预算。
6. **跨文档共享数据需要继续审计。** 同一电量/课表不应因画布数增加而重复读取、序列化和解码；已经有摘要与单实例去重，需要用多实例负载验证。
7. **系统备份恢复没有应用扩展。** 当前 module 声明了 form、formEdit、share，没有 backup 扩展。华为提供 BackupExtensionAbility 与临时备份目录能力 [S12]；接入前验证一致性快照、素材打包、恢复顺序和失败回滚。应用云同步声明继续关闭。

## 4. 原生能力的验证安排

| 候选能力 | 当前依据 | 开发前需要得到的结果 |
| --- | --- | --- |
| 当前作品直接添加桌面 | 亿象鸿蒙使用教程有直接安装流程 [S2] | 找到当前 SDK 的公开接口，确认预绑定参数、同尺寸、用户取消、重复实例；继续使用系统确认和编辑页 |
| 低成本刷新 | 华为 Form Kit 提供框架托管刷新 [S13]；我们已有本地时间计算、摘要与 provider 检查 | 主进程冻结、跨日、锁屏/亮屏、多个组件的真实调用数、IPC 和图片准备次数 |
| 系统备份恢复 | 华为 BackupExtensionContext 文档和本机 SDK [S12] | 原生备份服务调用、非空库恢复、旧版本恢复、失败重试、完整素材可读；不新增 App 内云菜单 |
| 天气 / 步数 / 音乐 | 竞品其他系统的功能展示 | 公开原生接口、权限、数据来源、系统限制和维护成本；通过后再排入实现 |
| 动态效果 / 碰一碰 | Form Kit 支持有限自定义动效；官方案例有碰一碰分享 [S1,S14] | 仅在可用场景运行，验证刷新配额和开销；分享保留原生文件回退 |

## 5. 下一版的产品取舍

- 主交付：故障后能找回作品、编辑即时落地、多组件长期稳定、缓存可控。
- 跟进功能：成套本地模板、系统添加捷径、简单待办；复用现有多尺寸、共享能力和作品格式。
- 保留：HDS 浮层与材质、自由拼贴、系统绑定、单 sheet 课表导入、无 App 内云菜单。
- 暂不扩张：壁纸商城、设计师社区、热搜后端、账号体系。先完成数据安全和离线体验，再按真实需求扩展。
