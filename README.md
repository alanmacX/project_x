# FridgeMemo

原生 HarmonyOS / ArkUI 卡片白板。App 与桌面 Widget 共用作品和布局，手机／平板仅提供 4×4 组件，并读取宿主实际比例。

## 功能

- 卡片直接拖动；点按显示删除、缩放、编辑和旋转控制；图层列表处理重叠卡片，组合与排序工具浮在列表上方。
- 多画布支持切换、新建、复制、重命名和删除；每张桌面组件绑定自己的画布，App 切换作品不会替换已绑定的桌面内容。
- 单卡由背景创作图层与一个能力组成，支持本地图片、GIF、文字和形状。整卡只在主页通过旋转控制点绕卡片中心旋转，靠近水平／竖直时吸附；设置页保留背景元素自己的移动／缩放／旋转及撤销。
- 系统主体抠图、紧致裁切、窄边柔化和误差受限轮廓简化；抠图固定白边。
- 画布背景：纯色、从卡片提取的智能纯色、智能多色、本地照片，以及本地生成的柔色预设。换图、改色或增删卡片后延迟合并计算；拖动、缩放、旋转和排序沿用已有配色，可手动重新取色以更新空间分布。智能计算在工作线程运行，结果缓存为一张背景图，App 与 Widget 共用。
- 单卡透明 PNG／实色 JPG、整板图片，通过原生系统分享面板分享。GIF 导出为静态图片。也可分享可编辑 `.fridge` 作品包，包含单卡或整板的图层、能力、组合和本地图片；接收者保存文件后，从“作品 → 导入作品包”导入。单卡追加到当前画布，整板创建独立画布。GIF 在作品包中保留原文件。
- 天气、时间、日期、月历、倒计时、纪念日、今日／年度进度；单卡最多一个能力，按内部可读区域适配尺寸。
- 本机电量、日程、待取包裹、URL 取数和课程表：截图端侧识别后确认取件码；URL 支持 JSON 字段选择或纯文本，失败保留上次有效值；课程支持开学日期、周次范围、单双周、今日／下一课。日程支持本地 `.ics` 导入的时区、每日／每周重复和例外日期；课程支持本 App 格式的 JSON 导入。
- 课程表可读取 WakeUp 五行 `.wakeup_schedule` 备份和包含课程数据的 JSON 导出文本；导入前预览课程、开学日期和节次作息，缺失作息需补全真实时间，确认后才追加或替换。仅含链接的在线分享口令不作为离线课程数据。电量有紧凑／完整两种电池图形布局，区分充电、低电、满电和旧读数。
- 单色圆角工具 UI、原生 ArkUI 控件、HDS 沉浸导航，App 随系统浅／深色，Widget 保留作品色彩。

## 开发

使用 DevEco Studio 和 HarmonyOS API 26 SDK，兼容 API 24。此仓库只包含 App 源码、配置和测试，不包含签名证书、密码、个人照片、设备截图或构建产物。

```sh
cp build-profile.example.json5 build-profile.json5
```

在 DevEco 中打开项目并配置自己的自动签名。`build-profile.json5` 是本地文件，禁止提交；示例配置不带签名。通过 DevEco / hvigor 编译 `entry` 模块。

测试运行实际模型和服务代码，平台接口使用模拟实现：

```sh
node tests/model.test.cjs
node tests/appearance-lifecycle.test.cjs
node tests/share.test.cjs
node tests/template.test.cjs
node tests/canvas-capabilities.test.cjs
```

跨平台运行测试时，用 `FRIDGE_TYPESCRIPT` 指定已安装 TypeScript 模块路径。原生分享、分割与实际桌面呈现还需设备验证；CPU 耗时不等于实际呈现帧率。

### 桌面同步与组合
编辑修改提交后即主动同步桌面，保存队列与桌面 IPC 分离，待发送内容合并为最新版本，失败不会被记作成功。图层“多选”支持组合整体移动与取消组合，卡片内容仍可独立编辑。抠图采用边缘透明度柔化、受限轮廓压缩和圆连接白边。

时间提醒与普通 widget 刷新是不同系统机制；未来后台提醒需要申请华为代理提醒开放能力，本版尚未实现提醒。

电量在前台通过系统广播更新，组件通过可见回调和系统调度刷新。单次下次刷新受系统最短 5 分钟和配额限制，不保证后台逐秒更新。读取系统全部日历需要 `READ_WHOLE_CALENDAR` 受限权限和对应 ACL 资质，普通签名包使用本地日历文件导入；华为快递元服务没有已确认的公开包裹读取接口。附属设备电量需要 Wear Engine 的设备支持、服务开通和用户授权，本版仅提供本机电量。

智能多色移植 FluidGradient 的实色径向核心、底层叠加、Overlay 高光和强模糊结构，合并重复色调，保留卡片位置影响。App 通过 ArkUI 合成器持续移动／缩放两层色域，无逐帧 JS 或图像生成；设置预览、桌面和图片分享使用缓存的静态画面。许可见 `THIRD_PARTY_NOTICES.md`。


### 教务课程表导入

课程卡 → 导入课程表 → 从学校教务导入。原生选校、App 内 ArkWeb 登录、课程/开学日期/作息预览，确认后才写入当前卡片。账号与登录态仅在隐私 Web 会话内；课表本机处理，不经过本 App 的服务器。WakeUp 备份仍可作为可选迁移入口。

学校适配资源来自 [qingyu_warehouse](https://github.com/Mutx163/qingyu_warehouse)，固定快照 `42474728fd1d6537c6ece020aa16d117c18d2d2d`，MIT（版权与许可随包保存于 `rawfile/schools/LICENSE.txt`）。目录包含 232 所学校、4 类通用教务入口，另有自行实现的强智通用网页解析：共 237 个目录项、249 个脚本。排除测试/在线分享服务和两个需另外处理服务器表达式的适配。更新用 `scripts/sync-school-adapters.py <适配仓库路径>`；App 不下载执行远程脚本。

这些数字表示资源覆盖，**不代表全部已通过真实学校账号验证**。学校页面变更、SSO、校园网、跨域 iframe 和特殊验证码仍可能导致个别入口失败。子页面入口可直接在同一登录会话内打开课表 frame；不会绕过学校登录。课程按完整周次数组校验并保留跳周；缺少真实作息时必须在预览补全；不会静默覆盖既有课程。

### 界面规范

应用界面以主页为基准：白色/深色底、米白/暖深色的圆角分区，不以不同色块区分功能。分区圆角 20、内边距 16，控件高度至少 44；常用选择为药丸，输入和复合操作为圆角矩形。选中状态使用深色填充与反色文字，分区不叠加装饰边框；边框留给输入、图层选择与作品本身。HDS 沉浸导航负责撤销、添加、重做、完成，危险操作使用红色文字。

卡片编辑保持预览与图层可见，设置跟随当前选中的图层。能力配置先于位置设置；能力列表点“更换”才展开，文字/图片元素不混入整套能力配置。内容颜色归入能力分区，分享与复制是末尾的并列次级动作。主页组合与排序按钮独立浮在图层列表上，不新增工具栏底板。课程、颜色、取值、教务导入沿用同一套颜色与按钮状态；课程弹窗把可滚动表单与固定确认操作分开。

UI 调整不在拖动回调加入图片处理、轮廓运算或配色提取；图层切换仅影响设置和选择状态，作品渲染与现有动画缓存保持独立。

### 假期与调课（v30）

课程能力 → 假期与调课。默认按已公布的 2025–2026 年国内放假日期暂停常规课程；国家补班只标记，不推断学校补课。学校规则可覆盖假期：指定日期照常上课、一段时间停课、将原日期整天课程移到新日期；单节课支持取消、改日期、时间和教室。整天停课优先于单节补课。移走的课程不再留在原日期，单双周按原日期计算。重新导入并替换课程会清除旧课程的单次变动，保留学校校历。

使用 ArkUI 原生日期/时间选择器、Select 和文件选择器；假期 `.ics` 由本机 TaskPool 与原生 `i18n.HolidayManager` 解析，不上传。接受明确日期的全天事件，正确处理排他性的 DTEND；循环规则与普通带时间日程会提示拒绝，避免误把普通约会当成停课。未知年份不沿用旧安排，可导入或手动设置。日历显示小尺寸的休/班标记，课程和桌面组件共用计算逻辑；刷新边界包含午夜，但后台刷新仍受系统频率与配额限制。

官方安排：[2025 年国务院办公厅通知](https://www.forestry.gov.cn/c/www/szxx/594663.jhtml)、[2026 年国务院办公厅通知](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)。鸿蒙原生 HolidayManager 是文件解析器，不等同于读取系统日历 App 的内置假期数据库。

产品仍是本地优先 App：课程和校历解析、保存、展示在本机完成；教务登录和获取课表直接连接学校，需要联网。没有自建账号/课表服务器。导入是本地快照，学校临时调课需要重新导入或在本机修正，不承诺自动后台同步。
