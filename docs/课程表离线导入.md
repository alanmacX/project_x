# 课程表：本地 ICS 导入

冰箱贴只读取用户选择的本地文件，不登录教务、不解析在线分享口令，也不自动联网更新课程。

## 鸿蒙 WakeUp → 系统日历 → ICS

已在 MatePad Mini / HarmonyOS 7、WakeUp 6.1.90 真机核对：WakeUp 分享菜单只有「导出到日历」「在线分享课表」「分享 App」，「导出到日历」是写入系统日历，没有直接保存 ICS 文件的选项。官网的跨平台导出说明不能据此直接套用。

1. 在 WakeUp 中选择学校，登录教务并导入课程，核对日期、单双周、地点和学校作息。
2. 在 WakeUp 课表页点右上角分享 →「导出到日历」，设置日历名称和提醒，完成写入。
3. 在系统日历主界面点右上角更多 →「查看全部日程」。
4. 长按一门课程，选择「多选」，勾选需要的本学期课程。仅选择 WakeUp 创建的课程；不要混入私人日程、全天节日。若列表只包含自己的课程，可以全选。
5. 点击底部「分享」。真机已确认可一次分享 9 条重复日程。
6. 点击分享面板里的格式下拉，将默认「日历日程(.vcs)」改为「日历日程(.ics)」。
7. 点「另存为」，保存到本机文件，例如 Download。
8. 在冰箱贴课程表能力中点「导入课表」→「选择课程日历 .ics」，核对周课表预览，再确认替换或合并。

如果分开分享了不同课程，也可一次选多个 ICS（最多 32 个）。不同文件的首课日期会统一换算，不会错位到同一周。单门课程详情的分享按钮只分享这一条重复日程；整表请使用上述多选路径。其他版本若支持直接导出完整 ICS，可以跳过系统日历。

[WakeUp 官方跨平台导出说明](https://www.wakeup.fun/doc/export_schedule.html)只作为背景参考；以上步骤按真机核对。冰箱贴读取课程日期与时间，不导入提醒、不自动创建通知。

## 导入规则

- 根据 ICS 中的实际开始、结束时间排课，不猜测学校的节次。
- 支持单次课程、每日 / 每周重复、单双周间隔、EXDATE 停课例外与 RDATE 额外日期。
- 不连续周次分别保留，课程地点或时间变化会成为不同安排。
- 使用最早一节课所在周的周一作为内部周索引，保持实际日期。ICS 导入预览不允许修改这个索引，避免整学期日期被平移。
- 当前不支持 RECURRENCE-ID 修改单次重复、每月重复、全天课程、跨午夜课程。遇到这些数据会拒绝导入并提示，不会静默生成错误课表。
- 文件最大 1 MB，一个学期最多 60 周 / 4096 次课程；压缩后最多 128 条安排。
- 导入是一个离线副本。WakeUp / 日历里的调课不会自动同步，变化后重新导出并导入。
- 假期与调课仍使用课程卡自己的设置；合并不同学期时需要创建另一张课程卡。

原有 WakeUp 本地备份文件与导出文本保留为兼容入口，其结构解析本身不需要联网。
