# 2026-10-10 UI 和场景竞态回归

## 修复

- 文档导航统一使旧定时动画失效，复位移出阶段；异步场景解析在画布切换/场景导航期间不应用结果。导航完成后重新安排定时边界。
- 定时面板的异步打开采用最新请求编号；用户转到背景、画布或离开页面后，旧请求不能重新打开面板，也不能弹旧错误提示。
- 场景开关采用每条规则独立请求编号。较早的读取失败/成功不能撤销较新的开关；删除后的规则回调不能重新保存规则。
- 旧版定时场景迁移生成独立文档，不临时切换当前编辑文档；重叠迁移请求合并。保留源画布尺寸、背景和卡片。
- 删除场景校验目录类型、等待发布队列、清理文档/轮廓缓存/发布队列。传入普通画布 ID 不删除任何数据。
- 场景编辑返回目标已删除时，返回现存的普通画布。删除画布确认时重新判断当前文档，避免使用打开对话框时的旧状态。
- 先准备轮廓，再提交新画布的可见标题、背景和卡片，减少异步准备期间的混合画面。
- 编辑选项栏按按钮数量保持原生组件身份，导航栏不参与内容淡出；内容区保留原生过渡。
- 场景列表标记当前编辑项；删除普通画布提示与当前桌面跟随策略一致。

## 验证边界

59 个宿主生产模型/API 模拟测试套件通过；HarmonyOS debug HAP 编译通过；previewer 纯模型与生产代码校验通过。

本轮仅连接手机比例模拟器。实际操作核对：卡片进入编辑、底板/能力图层切换、系统返回、桌面 Form 点击进入 App、回到首页。截图核对嵌入 sheet、预览和侧边图层布局。前一轮已核对原生时间选择器修改后的标签及保存后列表。

新增/扩展的竞态测试执行生产方法，覆盖过期动画回调、面板请求重排、隐藏窗口、开关请求失败乱序、返回目标删除，以及迁移期间切换当前画布。它们不等同于物理设备帧率测试。

模拟器日志仍出现系统 PixelMap/QoS、HDS 资源解析回退和 Sheet 默认 radius 参数诊断；截图中原生符号与 sheet 显示正常。本轮没有把这些系统日志宣称为已解决，也没有据此改动材质或用自绘控件替代原生控件。真机高刷新率、多设备横竖屏需要后续验收。
