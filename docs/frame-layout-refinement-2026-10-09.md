# 外框布局重写与横屏桌面验收

原外框通过 `onAreaChange` 保存尺寸，再用数值绝对定位右边、底边与四角。桌面容器改变尺寸时，背景和裁切已使用当前布局，外框却依赖另外一次测量回调；这套设计允许旧尺寸和新尺寸共存。真机截图复现了右框被裁切、底框不贴底的问题。

这一轮的 Row/Grid 临时尝试已全部移除，没有保留偏移补偿或接缝修正。外框重写为 ArkUI `RelativeContainer`：

- 四角宽度是当前容器宽度的 8%，通过 `aspectRatio(1)` 保持正方形，直接锚定容器四角。
- 四条材质边通过相邻角块的边界确定四个约束，原生布局计算位置和尺寸。
- 删除外框所有 `@State` 测量尺寸、尺寸属性和回调。外框不向桌面根节点反馈尺寸，也不接受 App/分享传入的尺寸副本。
- 中央没有图片，保持真正透明；无模糊、Canvas 重绘或材质实时计算。八片离线素材和批准的外观参数保持不变。
- App、桌面、预览和直角分享使用同一个组件。桌面本身的尺寸测量仍负责卡片内容缩放，和外框布局没有反馈关系。

华为 SDK 标注 RelativeContainer 支持 ArkTS 卡片；四个锚点属于当前 RelativeContainer 的直接子节点，相邻边之间没有循环依赖。

2026-10-09 真机验收：MatePad Mini 横屏桌面，安装修复包后右边、底边、四角完整闭合，没有 Row 尝试中出现的接缝。打开 App 再返回桌面后保持闭合，背景刷新没有挪动外框。保留截图在本地 output 中，未随代码上传。此次没有进行实际物理旋转、所有机型或每种材质的真机全覆盖，不将锚点布局的结构保证描述成所有设备都已验收。

编译与签名包构建通过，生产预览契约已重新生成。回归检查保留了透明中心、所有背景可使用外框和分享图直角边框检查，并约束外框不重新引入旧尺寸测量状态。
