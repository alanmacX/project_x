# 木质外框、静态创作与定时场景重构

## 外框

背景外框增加胡桃木和浅橡木，和白岩共用已选定的外沿几何：600px 研究宽度下，宽 18、深 16、纹理 20、倒角 33。外框贴画布实际外边界，中央保持透明；支持所有背景、深浅外观以及分享图直角版本。App 和桌面使用预生成的八片素材，不在拖动或切换时生成噪声、模糊或材质着色。

## .fridge 创作能力

创作 skill 对齐当前的背景材质、自由 capability 布局、挂钩/边缘参数、专辑样式及密度约束。版本契约从生产模型生成，并区分可以创作的字段和仅供运行时使用的场景策略。

新增两条可运行的创作工具：

- `scripts/fridge-static-render.cjs`：受约束的本地 HTML/CSS/SVG 静态创作，保留源码与外观缓存，可从透明度生成真实异形轮廓，并嵌入原生 capability。创作时截图，运行时不需要网页或脚本。示例为 `skills/fridge-create/examples/static/silhouette.fridge`。
- `scripts/fridge-compose.cjs`：将多个单卡包组合成可编辑画布，重新编号卡片、元素和素材，保持图层与形状。导出会清理 provider 用户数据，接收端使用自己的数据源。

高级视觉可用静态纹理、矢量装饰、排版和异形轮廓实现；实时内容仍交给原生 capability。禁止把整个画布拍平、把私有记录写进模板，或使用网络资源和无限动画。源码、缓存及生产解析器校验组成可升级的创作基础。

## 定时场景

每个场景独立存储，只有一张中央卡片，不借用主画布的常驻卡片。场景编辑沿用画布与卡片编辑器，顶部标注“定时场景”；普通画布保持原有绑定。入口是“我的画布”旁的系统 timer symbol 小按钮。

规则只有一次触发时间，可选指定日期或每周重复。最长显示时间默认 15 分钟，范围 1–120 分钟。点击中央卡片或到期恢复当前主画布。后来的触发强制结束先前场景；即使新场景已关闭或到期，也不会再次显示被抢占的旧场景。保存/启用规则不会补触发保存之前的时间点。

过渡先将当前卡片移出四边，再引入中央卡片；恢复时返回原位。计算退场范围包含伸出主体的内容、衬底及挂钩，避免残留。数据和轮廓在动画前准备，位移由 ArkUI 动画执行。中央卡片的关闭点击区域也包含这些外延，同时保持形状命中校验。

旧版中央展示首次进入定时面板时迁移到独立文档；旧摆放快照仍保留在原文档中，但不再作为新版场景的执行模式。迁移键避免中断后重复迁移。

## 主画布轮换与复制

主画布轮换独立于定时场景：手动、按时间、跟随系统深浅三个互斥模式。时间模式以固定 00:00 起点连续覆盖一天，最多 12 个时段；修改分界同步调整相邻时段，不留空档，不允许重复起点。跟随深浅模式只配置浅色和深色对应画布。

复制按钮使用原生菜单，区分“复制”和“复制到别的场景”。目标可选普通画布、已有定时场景，也可新建定时场景。复制到已有中央卡片的场景需确认替换。普通画布仍遵循 16 张上限，定时场景只允许一张。

## 修复与效率

- 仅修改规则时也会使桌面发布队列失效，避免卡片 JSON 未变而跳过更新。
- 跨文档复制走同一串行发布队列，避免绕过队列造成后续更新被错误去重。
- 中央卡片的数据刷新写回所属场景文档，避免污染主画布位置和内容。
- 新场景抢占后，不再为旧场景的过期点安排无效刷新。
- 全局规则解析采用快照，避免异步读取过程中 UI 改动规则产生竞态。
- 文档按需读取，避免启动时加载所有画布和场景。外框材质、静态创作外观使用缓存。

## 验证和限制

2026-10-09：53 个测试文件全部通过；ArkTS 编译和签名 HAP 构建成功；生产预览模型一致性检查及 skill 校验通过；白岩、胡桃木、浅橡木通过浏览器生产预览器检查。覆盖独立场景存储、跨午夜、抢占和确认、复制/替换、全天轮换、静态素材与隐私清理。

当前 HDC 未检测到设备，以上结果不代表真机 UI 或高刷新率验收。还需要连接设备验证原生 sheet、小屏布局、系统深浅切换和桌面往返帧时间。

桌面不是常驻的精确计时器：刷新受系统最小间隔和后台调度影响，扩展不存活时也不能即时收到系统外观事件。短时场景可能延迟，甚至在系统允许刷新前已经到期。前台 App 按边界执行；桌面每次获准刷新都计算当前应显示状态，而不是依赖历史回调逐个播放。现有实现不能作为精确闹钟或可靠提醒服务承诺。
