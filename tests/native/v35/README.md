# SketchLab 原生验证

MatePad Mini，HarmonyOS7，1600×2560。覆盖安装，不访问或修改 FridgeStore。

- 自由模式粗略椭圆：201点整理为50锚点，底板填色、缩略预览可见。最初 SVG 字符串 Path2D 在高密度屏上按物理像素解析，造成轮廓偏移／缩小；改为逐条 vp 路径命令后，轮廓与原稿位于同一坐标系。
- 系统模式：通过系统输入工具产生真实触摸事件，停笔700ms；收到 Pen Kit `shapeType=1` 回调并显示“系统已整理为直线”。手写笔事件路径同样收到真实回调。测试期间亦记录到椭圆 `shapeType=2` 的原生回调；未据此断言所有支持图形的识别率。
- 撤销后的按钮状态为撤销禁用／重做启用，重做后反转；原稿对比和填色是原生 Toggle。
- 开启“仅手写笔”后，注入手指拖动不改变既有草稿；随后手写笔事件仍可整理成形。此测试不等同于真实笔的压感或硬件防误触认证。
- 模型测试覆盖开放路径端点、原稿不被修改、闭合接缝、尖角位置、示例轮廓面积变化小于4%、长笔迹输出上限。

可复现单笔原生事件（需先选择“一笔成形”，坐标为此设备竖屏画布内的物理像素）：

```sh
hdc shell uinput -S -m 550 1100 1050 1118 -k 700 600
```

内置粗略示例不经过 Pen Kit，不将示例整理结果当作智能识别证明。当前横屏分栏为响应式布局；尚未完成本轮横屏真机专项测量。屏幕刷新率和一次5ms曲线计算不是持续帧率证明。
