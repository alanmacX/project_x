# Canvas selection and timed scenes

Manual canvas choice flushes the document and active catalog selection before widget IPC. It enables durable desktop-follow-selection policy, migrates all registered form bindings, waits for old deliveries, invalidates acknowledgements and publishes the selected canvas. Explicit selection pauses automatic rotation while retaining all slots/theme choices. Scene editing and inactive exports never activate or bind a central scene as a normal canvas. Generic widget launch ignores cached canvas IDs; explicit card links retain their target.

Timed scenes appear under their own subtitle in the canvas picker. A new scene is enabled by default; its timing editor also exposes its enabled state. Saving/enabling/removing policy immediately re-arms foreground timing. An open timing panel no longer suppresses a due scene. Activation in the scheduled minute is allowed, while earlier starts remain excluded. Projection changes and timeout explicitly invalidate widget delivery acknowledgement even if editable bytes are unchanged. Distant boundaries are registered immediately rather than waiting for an hourly refresh.

Validation: debug assembleHap succeeded; 56 host regression suites passed, including extracted production foreground timer methods (due boundary with timing panel open, timeout restoration, unchanged-byte desktop delivery, source isolation), real store with mocked Harmony APIs (durable restart, all registered bindings, stale bindings, retained rotation configuration), and production ability routing. Previewer bundle/fingerprint matches app models.

Phone emulator UI: canvas list shows timed-scene subtitle; selected canvas 2 survived force-stop/relaunch; native rotation switch toggles on and off, with time configuration retained. Updated HAP installed on emulator. Physical-device desktop timing and frame rate were not measured in this pass. FormProvider's installed SDK declares a minimum 5-minute next-refresh delay; system delivery remains subject to scheduling/visibility. This is a visual scene scheduler, not a precision alarm guarantee.
