# 原生取色入口与工具复测

MatePad Mini，HarmonyOS 7 / API26，1600×2560，暗色竖屏，签名包覆盖安装。

- 首页“我的画布”使用系统 chevron_down。点击箭头所在区域打开现有画布选择面板，返回正常；长名字使用单行省略，图标单独占位。
- 元素、底板、能力文字的设置行直接打开系统 HDS 色彩浮层。原生网格／光谱／滑块页签可见；布局中没有额外“选择颜色”自制弹窗。整板背景共用 ColorSetting，未切换用户当前智能多色背景。
- 元素色原来为自动：选 #191919 并关闭系统浮层后显示“自定义”；撤销恢复“自动”和 #F4F3EF 样本；重做再用旁边恢复默认按钮，状态与样本再次恢复。测试颜色最终恢复自动。
- 修复 HDS 内部初始色不随外部撤销更新的问题：外部恢复重建取色实例，本次选择不重建；旧实例或已离开来源的回调忽略。颜色状态直接读受观察字段，不再用被冻结的 Builder 临时值。
- 首页组合多选使用原生圆形 Checkbox。点击第一个复选框、第二张卡的整行，两者均为 checked，组合数量变为2并启用；取消后退出选择，没有执行组合／删除。复选框与编辑按钮分别命中。
- 图层选中标记改为系统 checkmark；添加、返回、撤销、重做、清空用系统 SymbolGlyph。文字缩略图保留 A。
- 手绘实验模式控件占满可用宽度，笔限定开关移入预览设置；示例用原生菜单。选择粗略椭圆后撤销／清空启用，撤销后仅重做启用、显示“已撤销”，重做恢复草稿并显示“已重做”。工具启用状态直接读观察字段。实验不使用 FridgeStore；未进行真实手写笔专项测试。
- assembleHap 与 git diff --check 通过。未做 API24 真机、浅色／横屏专项或持续帧率测量；API24 保留原生 RGB Slider 单层兼容面板。色彩仍为现有 RGB 模型，透明度在独立元素／能力设置中管理。
