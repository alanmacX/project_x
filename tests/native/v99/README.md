- WidgetPayload 的专辑图片清单生成和图片映射共同使用同一个 frameTime，避免跨轮换时刻时把 A 的清单与 B 的图片同时提交。回归用真实 60 分钟轮换参数，模拟两个查询分别在边界前/后；修复前断言失败，修复后缓存清单与图片 key 完全一致。
- WidgetSync 对其他绑定画布的损坏 JSON / 非数组 cards 做隔离，不把它转换成空白默认画布，也不阻断正常画布的更新。损坏原始记录及该组件原有画面保留；当前需要更新的画布出错仍会报错。
