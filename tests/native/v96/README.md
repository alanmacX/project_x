# Native irregular reading edges

Pura X Max simulator screenshots, actual ArkUI paths and text. Materials held constant.

- Cloud: broad smooth lobes, no sharp tips; most expressive option.
- Handmade paper: low-amplitude irregular edge.
- Pebble: gently asymmetric convex outline.
- Native toggle tests 210-vp normal and 160-vp compact labels with time and three course rows.
- Shared pure geometry retains a rectangular safe core. Automated containment checks cover 3 silhouettes, 6 aspect ratios and 4 pixel densities.
- Fixed complexity, no bitmap redraw loop, outline scan, runtime noise or Path.shadow rectangular artefact.
- Demo only; original materials and saved canvases are untouched. Entry: material study → 试边缘轮廓, or debug launch parameter demo=edges.
- Release build and all 33 test scripts passed. Desktop Form rendering and physical-device frame rate were not measured in this prototype round.
