# MatePad Mini 模板真机验收 · 2026-11-01

设备：MLR-AL10，1600×2560，OpenHarmony 7.0.0.111 / API 26。使用正式签名的 1.2.0 包覆盖安装。

## 真机发现并修复

- 空画布中央显示“添加卡片”，点击却只清除选择。背景点击现在在空画布时打开模板/创作选择器。
- 空画布的图层面板仍铺满剩余高度。现在按操作栏与内边距收起；已在真机确认大块空白背景消失。
- 平板竖屏编辑横向画布时，图层面板过高。堆叠面板限制为 320vp，列表保持滚动；横向画布、3 个图层和操作栏完整显示。横向侧栏布局继续使用可用高度。
- 模板选择器的“组合”分类缺少选中态。现在与其他分类使用同一套选中色彩。
- 未提取主体时显示无效的主体滑块；关闭主体后滑块仍可操作。提取成功后才显示主体控件，关闭主体时禁用变换滑块，开启后恢复；真机 accessibility 中验证 Toggle=false 时 Slider.enabled=false，随后恢复原设置。
- 新建模板立即调用刷新，但入场动画的保护条件把刷新跳过了。改为调用原来的前台刷新调度，在动画结束后读取数据；不新增逐卡计时器。
