# V94：真实 ArkUI 衬底材质实验

新增只读三档对比，不替换正式卡片的材质。入口：卡片编辑 → 上层内容 → 对比融合方案；可对当前卡片切换现有/A/B/C。并排查看入口复用真实 ReadingBacking 和 ReadingHook，以同一张本地照片比较笔触、挂钩。

- A：基底不透明度 70%，采色与云白混合 32%。
- B：82%，50%。
- C：90%，66%。
- 从本地 48×48 采样读取配色，仅在打开对比时执行一次 taskpool；中性阴影不掩盖有足够占比的彩色区域。
- 深色照片的采色会向云白提亮，以最暗透底条件保留深色前景对比度。
- 真实原生 Path，固定层数，无实时背景模糊，无随机或循环动画，无拖动期间的解码或采色。挂钩孔的多层 Path 共用同一绝对位置。
- readingMaterialStudy 仅放在预览副本，标准卡片恢复逻辑不读取它。正式 default=0，已有布局、材质不被这次实验替换。

Pura X Max 模拟器实际运行发布构建；mica-native-variants.jpeg 是 snapshot_display 原始截图，不是生成图。此截图样本是模拟器已存在的本地企鹅照片，不是用户真机的黄色角色。未做真机验收或宣称帧率达标。

Release 构建及全部测试入口通过；新增配色差异、最暗透底可读性、中性阴影过滤和切档无解码检查。
