# v61 上线前 debug（2026-10-06）

保持现有设计；真机 HUAWEI MatePad Mini / HarmonyOS 7 / API 26。

## 修复

- 删除画布：先等待正在发布的组件任务，再改变绑定并使已投递内容去重缓存失效。之前即使剩余画布内容已经成功投递过，重新绑定的组件也必须再次收到它；旧的在途任务不能覆盖新绑定。测试先复现失败，修复后通过。
- 时钟：原生 TextClock 在默认能力框中会把 HH:mm 换成两行，末位数字溢出。依据框内宽度限制字体，同时约束读数高度；世界时钟同样处理，进度读数限制单行。真机默认时钟和图片分享预览复测通过。
- 组件轮廓：Form 首帧重复执行后台已完成的轮廓压缩。场景包现在直接登记已经处理过的轮廓；未处理的旧数据仍走正常校验。
- 组件投递：复用本地持久化的轮廓缓存，要求版本、素材标识、完整原始轮廓一致，缓存格式异常或过期会重新生成。避免正常刷新、覆盖安装恢复时反复做拓扑计算。
- 去掉不适用于普通应用的 onChangeFormVisibility 假设，并纠正 README。当前 SDK 明确这一回调仅对系统应用生效，不应承诺每次桌面可见立即刷新。
- README 清除已移除的联网教务入口描述。
