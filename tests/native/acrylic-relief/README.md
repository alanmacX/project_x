# Marble frame, retained relief and whole-card gestures — 2026-10-09

The transparent frame is a 12-vp hollow sculpted marble bevel: opaque pure white (or explicitly chosen dark stone), with opposed outer/inner cut faces. Its full-canvas native shadow was removed. No centre fill is introduced. Social poster export uses the same frame with straight rectangular corners, drawn above the artwork; desktop keeps rounded corners. Native exported poster was inspected, including logo and signature. Captures containing personal artwork remain outside Git.

The previous silhouette face created 24 stroked Path shadow nodes per card. It now composites one transparent PNG containing two Gaussian shadows, a sidewall and a face. Generation runs in a taskpool worker; fixed 2x source images are reused by app and Form. Placement, rotation and capability data do not change the fingerprint; geometry and surface changes do. Paths and disposable artwork caches are bounded (128 entries/files). Form manifests include artwork and relief and replace images atomically. Derived paths are stripped from editable storage/import. Detached poster export explicitly prepares relief before snapshotting.

Visible capability rectangles, rotation and outside edge attachments are now included before silhouette bounds in hit testing. BoardCard's input host includes attachment overflow. Native MatePad test: dragging from timetable text changed both title/readout coordinates by exactly (-150,+110) screen pixels and moved the whole subject. Pointer ownership is determined only on DOWN.

Resize keeps the original CardFace/card/content identity and scales its retained texture during the pan; geometry and density reflow only at release. Overflow scans are cached for the source pose. Release no longer forces the whole data transaction through animateTo; handle recovery is staggered 32 ms. Unchanged board/layer containers are retained for geometry edits. Photo-only silhouettes with external capabilities bypass duplicate photo drawing and offscreen masking; interior artwork keeps its mask.

Validation: all 51 host test files passed; preview model identity/check and debug ArkTS signed build passed. Latest package installed and exercised on MatePad Mini. App and actual transparent desktop screenshots verified, plus actual system-share poster export (no send to recipient).

Performance evidence is limited to short reproducible native samples, not sustained FPS: the earlier resize release forced JSAnimateTo for 26.36 ms; final sample's longest JSAnimateTo was 2.93 ms. Final 40 dirty-update spans: p95 5.95 ms, max 18.75 ms (one above 16.7 ms). UI layout scheduler: p95 .70 ms, max 1.91 ms. The rare release update spike remains; do not claim refresh-rate saturation. Actual widget cold entrance was also traced: page JS initialization/load is still material (approximately 44 ms page module execution in the sampled build). Relief modules now load lazily and no bitmap generation is awaited by startup. Earlier unrelated launcher traces are excluded from comparisons.
