# 手机浮动画布工具

Mate 80 RS模拟器，127.0.0.1:5555：
- 竖屏首页只有底部画布药丸及独立添加，画布保持桌面比例居中。
- 点击药丸展开原生popup，可看到图层、选择、编辑、删除、背景和导入。
- 点击画布背景先关闭popup，再显示独立原生sheet；系统返回后回到首页。
- 在popup中进入画布菜单和定时场景，定时场景sheet正常显示，无依赖已经关闭的popup宿主。
- 横屏仍为浮动工具入口，popup包含可滚动图层，画布不因展开而缩放。

Workspace测试覆盖16种窗口及4种比例，手机/窄分屏启用浮动入口，平板常规窗口保持常驻工具。22个回归脚本通过，Debug构建成功。

修复已有定时测试在午夜前失败的问题：测试目标是10分钟后的事件边界，改为固定正午测试时钟，避免真实午夜成为更早的边界。产品刷新策略不变。
