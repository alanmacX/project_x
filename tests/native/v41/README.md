# 组合选框与慢速智能多色

2026-10-05，MatePad Mini，HarmonyOS 7 / API 26，深色横屏。

- 为避免改变用户布局，从“我的画布”创建了临时副本。
- 在副本中多选两张主体卡片并组合，选择其中一张后出现整个组合的选框、统一缩放和旋转手柄；成员原来的单卡手柄隐藏。
- 拖动组合缩放手柄，两张主体及其上层内容共同缩小，彼此关系保持。
- 拖动组合旋转手柄，两张主体共同绕组合中心转动。
- “取消组合”位于上移/下移按钮之后，各按钮独立浮动；点击后布局树立即没有“取消组合”，组合标题消失，恢复单卡手柄。
- 复测发现跨画布的选框会越过工具区；最终增加与画布相同圆角的裁切，手柄坐标始终夹在可见画布内；重新安装后在另一临时副本中再次组合，截图确认选框没有进入工具区。
- 临时副本已经删除，回到原“我的画布”；原卡片几何没有做测试修改。
- 智能多色原生动画改为 180 秒单程，往返 360 秒，漂移幅度 .20 → .08；共同静态背景承载主要颜色，App 的动态叠层仅 18%。未用后台推送驱动动画。

模型回归覆盖：不同画布比例下的组合中心、缩放/旋转与逆变换、取消组合后发布新渲染快照。签名 HAP 编译通过。

限制：此次没有记录 GPU 帧时间或最高刷新率，没有 API 24 真机、浅色/竖屏完整验收；定时提醒只完成文档调研，尚无桌面时序样机。
