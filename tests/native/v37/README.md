# 原生控件替换复测

MatePad Mini，HarmonyOS 7，1600×2560，签名包覆盖安装。检查了设置页、课程编辑、下拉菜单和首页图层入口；课程编辑以取消退出，没有新增课程。

- 字号改成系统 `CounterComponent`，保留原生按钮、长按提示与数值范围。发现原生 `value` 是初始值，外部撤销后计数器仍显示旧值；现在仅在外部数值恢复时重建计数器，并忽略已退出实例的回调。真机验证16→18→撤销16→重做18，撤销／重做按钮状态随历史同步，最终恢复原作品的18号文字。
- 底板配色和形状变为 `Select`。已有照片主体作为第五个形状选项，菜单中方形、椭圆、胶囊、自由边角、照片主体都可见；测试只打开菜单，没有改变底板。
- 课程表展示、主体外观、接口刷新间隔、单双周和手绘模式使用系统分段控件。真机检查课程表“下一课／每日概览”，打开课程编辑切到双周，星期菜单完整显示周一至周日；取消退出。
- 首页图层选择使用原生 Button；编辑入口作为独立相邻按钮，没有把 Button 嵌进另一个点击按钮。真机从首页分别进入文字卡和课表卡编辑成功。
- 点击元素颜色样本可打开颜色弹窗，再打开系统 HDS 取色器，原生网格、光谱、滑块三种页签可见。取消退出，没有应用新颜色；取色器入口半径设为22vp，避免默认入口过小。
- 操作按钮声明 NORMAL／EMPHASIZED，删除声明 ERROR。移除胶囊／圆角按钮上的手工圆角覆盖及普通操作按钮的细线框；保留分区填色和有意义的选中边界。应用操作按钮保持44vp高度，图标使用系统 SymbolGlyph，现有旋转与缩放手势位置保持原逻辑。
- `assembleHap` 与 `git diff --check` 通过。未在本轮逐一执行所有导入、分享、删除操作，也没有横屏／浅色专项检查或持续帧率测量。
