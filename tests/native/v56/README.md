# 浮层展开与画布抬升

Mate 80 RS模拟器竖屏，HDC 127.0.0.1:5555：
- homeCanvasSurface收起bounds [54,663][1266,1925]。
- 点击画布药丸，展开后bounds [54,185][1266,1446]。
- 系统返回收起后bounds [54,663][1266,1924]；差异1px来自原生像素取整，宽高没有功能性缩放。
- 从展开浮层点击编辑，再完成返回，画布bounds恢复 [54,663][1266,1924]。

Native popup显式设置进入280ms淡入+上移24vp+0.98倍缩放，退出220ms淡出+下移16vp。画布原生animateTo以相同进入/退出时长移动到安全区顶部/居中位置。过渡期间暂缓拖动命中，防止中间帧坐标错位；编辑入场读取抬升位置后再关闭浮层。

16种窗口/4画布比例的几何检查新增抬升目标处于安全区的断言。22个回归脚本及Debug构建通过。未据此宣称真机刷新率。
