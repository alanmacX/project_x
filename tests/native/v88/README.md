# V88 — 穿孔挂钩、笔触云母和内容安全区

本轮仅使用 Mate 80 RS 模拟器 `127.0.0.1:5555`，未操作已连接的真机。

## 修复

- 不规则轮廓原先按整个标签的宽高百分比起伏，文字留白却为固定 vp；长标签的凹口会深入内容区。新轮廓只在内容留白范围内起伏，吸附边保持平直。文字层独立限制宽高，长信息用原生换行、缩字或省略。
- ArkUI `Path2D` 的 SVG 字符串坐标按 px 解释；Canvas 的普通绘图使用 vp。模拟器检查发现衬底因此缩小，已显式转换路径坐标为 px，并添加回归断言。
- 挂签 / Dock 增加 20 个内容单位的上沿避让区（跟随能力缩放），尺寸下限和可用内容高度同步更新。孔洞使用 `destination-out` 真正清除透明度，可透出原始底图；细金属线分成纸外后段和从孔内露出的前段。
- 选位改为标签上的点按 / 水平拖动，另有三个原生胶囊快捷按钮，目标高度 44vp。拖动过程只更新本地预览，结束提交位置。
- 笔触用多层半透明刷痕、方向纤维、渐淡边缘和不齐的笔毛末端。核心内容区域始终有完整衬底。参考 [Adobe 纹理画笔](https://helpx.adobe.com/photoshop/desktop/apply-painting-techniques/brushes-presets/create-a-textured-brush-in-photoshop.html) 与 [Adobe 画笔纹理说明](https://www.adobe.com/products/photoshop/brushes.html) 中的纹理深度、笔触叠加和边缘渗色做法。
- 背景、孔洞和挂钩仅在尺寸或材质属性变化时重绘。尺寸是私有绘图字段，不写入响应式布局状态；没有定时器、随机纹理或逐帧轮廓扫描。

## 验证

- 全部 30 个现有测试入口通过，结果见 `test-results.txt`。
- 60,500 个内容安全区采样：五种衬底、五种边状态、四档缩放、五种宽高比例；包括极宽和极高的标签。穿孔与正文避让区另作断言。
- 原生竖屏、横屏截图：时间笔触、电量徽章、台历贴片、世界时钟、倒计时挂签、日程 Dock。
- 持续 43 次内容变化后检查长标题、空日程、67 / 100 电量。挂钩直接拖动至右侧、快捷选择左侧，正文保持在轮廓内。内容改变时材质跟随实际内容大小变化。
- 更新停止后连续 16 次截图，三个静态材质 / 卡片区域相对首张平均像素差均为 0；结果见 `sampled-stability.json`。这证明被采样区域无持续闪烁，不代表真机 FPS 或全帧时间测试。
- 验收页源码仅留在测试目录，生产入口和路由已恢复；最终 release HAP 重新构建。
