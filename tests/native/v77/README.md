# 图像增强与融合对比页验证 · 2026-10-07

## 功能范围
- 抠图底板设置、画布照片背景各提供“提升清晰度”。
- API 26 CoreVisionKit 原生 ImageSRAnalyzer，在 TaskPool 内执行；不增加网络权限。
- 输入长边最多 1280px，结果长边最多 2048px；单任务串行，避免并行处理大图。
- 透明主体先延展边缘 RGB 防止黑边；原 alpha 通过原生 PixelMap 缩放后恢复，轮廓、卡片比例和布局不重新生成。
- 原图／增强后可切换。确认前不更新数据；取消删除结果，保存原素材；任务期间切换画布或更换素材则丢弃过期结果。
- API 24 不调用超分，提示需要兼容设备；未做 API 24 真机验证。

## MatePad Mini / API 26
使用与生产相同的后台函数，临时测试 Ability 不进入生产包。
- 179px 照片：524ms 完整任务，716px 输出。
- 1200px 透明主体：7527ms 完整任务，2048px 输出；1705895 个全透明像素，118446 个半透明像素。
- 原生超分只增强 RGB。恢复透明蒙版由本应用处理，避免平台输出不保留 alpha 的问题。
- 这是离线图像处理，增强可能平滑或改写细节，必须由用户确认。

## 对比页转场
同一卡片、同一设备的 hitrace（ace/app/graphic）：
- 初次调整后仍发现 aboutToAppear 1380.92ms，原因是三种方案把已缓存轮廓展开、又重复执行轮廓简化。
- 修复为共用 renderContourKey，不再重复简化；只读路由不触发整套画布保存、桌面图像发布或返回重同步；预览按顺序挂载，复用主体深度缓存。
- 修复后进入 UI 帧处理最长 12.11ms，main_longest 无长任务；退出最初修复记录 UI 最长 3.57ms。
- 发布包再测：进入 UI 最长 10.90ms，退出 2.52ms；退出的框架渲染上下文回收另有 34.04ms 任务，仍可能掉一帧，不能宣称零掉帧。
- UI 帧处理时间不等同于屏幕呈现 FPS，不宣称所有设备顶满刷新率。
