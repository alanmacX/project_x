# 紧凑设置 / 原生任务弹层 / 电量环 · 2026-10-07

## 设计取舍

依据 Apple HIG 的 scoped task / 保留父界面上下文原则，短任务不再默认占满屏幕：
https://developer.apple.com/design/human-interface-guidelines/sheets

ArkUI bindSheet 原生处理进入退出、拖动、遮罩、关闭和挡位；height 是初始高度，detents 是停靠高度：
https://developer.huawei.com/consumer/cn/doc/doccenter-dev-faq/faqs-arkui-1039

- 融合对比从整页导航迁至编辑页原生 sheet。一次只渲染一个样本，原生分段控件切换三个方案，不修改原卡。
- 底板形状与边缘、布局与图层由撑长 inspector 的展开块改为原生 sheet。
- 能力选择、画布背景、定时场景由默认 LARGE 改为有初始高度和扩展挡位的面板；新打开时窗口 >=600vp 用 CENTER，窄窗口用 BOTTOM，内容限宽560/620vp。已打开的系统面板旋转时可保留其原生底部锚点，内容同步适配。
- 配色、形状、位置、衬底、融合采用左标签+右 Select 的行式设置。ColorSetting 自动/自定义说明横排；TextArea 72vp，操作点击区域仍44vp。
- 短内容 Scroll 顶部对齐。对比预览按弹层实测高度缩小，整个内容可滚动，底部留白；后台保存逻辑不再因比较打开而跳过。
- 异形比较预览在测量稳定32ms后准备缓存，关闭/切换/旋转用generation避免迟到任务更新视图。
- 复杂周课表、课程表导入和编辑保留原有对话框，避免小弹层妨碍查看完整内容。本轮未迁移为 sheet。

## 电量

原生 Path，底部72°缺口，剩余288°显示进度，百分比位于缺口，充电绿色与居中系统闪电符号，<=20%红色，旧读数弱化。紧凑模式不显示辅助说明。App和桌面共用 BatteryCapability，没有定时/逐帧绘制回调或新增刷新请求。

Path commands 用物理像素，布局与 strokeWidth 用vp；模拟器截图发现密度混用会产生左上角小环，已通过UIContext.vp2px修复。完整最低96×96，紧凑64×56，沿用已有.8可读缩放下限。
