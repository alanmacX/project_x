# 设置 UI 原生验证

MatePad Mini，HarmonyOS 7，1600×2560；覆盖安装签名包，使用已有作品检查，没有修改卡片内容或背景模式。

- 编辑页“背景创作／上层内容”为原生 ArkUI SegmentButton。六次交替点击后，再从背景滑向上层，设置区显示天气来源与能力排版，选中状态一致。
- 文字对齐与阅读衬底的三段选择、画布背景的四段选择，在真机截图中显示完整；已有智能多色模式保持选中。
- 能力选择弹窗打开，切换生活、自定义、时间分类后关闭，没有替换既有能力。
- 选择背景底板后收起设置：原生布局树中“底板形状与边缘”仅出现一次，底板配色、照片主体形状及主体外观字段均已移除，没有退出节点残留。
- 设置内容按分区／图层／能力类型切换；输入内容和实时几何不进入转场标识。分段选项按标签与主题缓存，外部选择更新不重建选项。
- `assembleHap` 和 `git diff --check` 通过。本轮没有持续帧率测量，也未完成横屏、浅色及所有能力组合的专项真机检查。

统一动效：分区180ms淡入＋6vp位移、90ms淡出；原生弹窗200ms进入、140ms退出。系统分段控件保留原生滑动选中反馈，连续输入和画布手势不附加设置转场。
