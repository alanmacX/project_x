# v34 设计与时间能力验证

DesignCapabilitiesQA.ets 是隔离的原生 UI 夹具，可临时复制至 pages/qa、注册 main_pages 并将 EntryAbility.loadContent 指向该页。它不初始化 FridgeStore，不访问用户作品。蓝色按钮仅作为 QA 控制，产品设置使用 AppDesign 的中性色与原生 Select/TextInput。夹具日夜切换只切自身 UI 颜色，不改变系统色彩设置；系统栏对比度不作为夹具检查结果。

MatePad Mini / HarmonyOS 7 实测：

- 最小和完整世界时钟、农历；纽约时间／时差，切换到加德满都后预览立即更新且正确显示2.25小时时差。
- 农历显示中文月日和丙午年；闰月、新年和满月另由真实模型与 ICU 计算回归。
- 能力选择页搜索农历、键盘避让、关闭；深浅色组件和横竖屏。
- 正式页面背景／上层切换：紧凑图层列表、A缩略图、正确底板标签，不再出现重复的能力设置底板。
- 正式页面临时新建世界时钟，确认原生时钟日期格式、来源分区和城市设置；测试卡片循环拖动六次。临时卡片结束后删除，不修改原有卡片。
- 正式页面的选择框与能力显示区域：修正16vp偏移后，真机布局数据为显示区域[235,407][676,750]、选择框[236,407][677,750]，垂直一致、水平仅1px取整差。
- 正式横屏编辑页核对布局；当地10月4日23:33时，东京时钟正确显示10月5日00:33。空卡片上层页不显示不存在的能力缩放手柄，能力选择页的纯创作入口固定在底部。

测试结束恢复正式 EntryAbility、main_pages 和自动旋转，移除临时 pages/qa，再重新构建并安装。无需卸载，保留现有作品。

没有测得持续帧率，不把拖动成功、设备120Hz模式或模型计算耗时当作120fps结论。未跨真实午夜／夏令时边界长时间采样桌面更新延迟。
