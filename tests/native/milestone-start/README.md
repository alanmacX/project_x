## 执行

模拟器原来安装的是 1.0.0 / 1000000 开发包，沙箱中有 11 张画布、已保存课表和 14 个素材文件。未将它称为市场正式 1.0 包。

1. 停止旧进程，把完整 base 沙箱复制到本机并生成文件 SHA-256 清单，共 42 个文件、约 10.6 MB。代码安装目录不允许读取，记录这项结果；沙箱备份已完整取得。
2. 保留数据覆盖安装 `1.2.0 / 1002006` 本地隔离版，没有卸载或清数据。
3. 当前生产适配层将旧 Preferences 导入 SQLite，读取目录和 11 份画布。
4. 比较迁移前 XML 与 SQL：11/11 份画布 JSON 逐字一致，目录逐字一致，已保存课表逐字一致。
5. 14 个原素材都存在且 SHA-256 一致。数据库 `integrity_check=ok`。
6. 通过 UI 进入原画布编辑页、返回作品库，停止进程并重新启动；再次复制数据库，11 张画布保留，11 份 JSON 仍与旧记录一致，`integrity_check=ok`。

这次检查覆盖旧安装的实际沙箱迁移和冷启动，不包含修改卡片后的保存、桌面绑定压力或长时间动画采样；对应任务继续按 milestone 的独立验收项执行。

## 发现的界面问题

旧库中多张空画布使用纯白背景、没有画框。浅色首页上，这类有效预览的边缘不可辨认，看起来只剩名称。需要为这类作品提供轻量边界或空画布标识，保留原作品的颜色和导出效果。该问题记录在 S08 / U04，当前没有通过更改作品数据掩盖。
