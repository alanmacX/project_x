# 图层组织、分享、阅读衬底与能力定位

MatePad Mini，HarmonyOS 7/API26，2560×1600，暗色横屏；签名 HAP 覆盖安装。截图与布局转储留在本机临时目录，未上传用户画布素材。

- 组合成员在列表里相邻，显示小标题“组合 1”；原来的叠放顺序不因列表聚合而改变。每张卡片编辑后有独立系统垃圾桶按钮。选择已有组合时，上移、下移仍独立浮在列表底部，取消组合位于原删除位置；没有新增工具底板。没有提交取消组合或改变原组合。
- 多选但未选满两张时，组合按钮保留清晰灰色文字，点击不会执行。再次点击已选图层退出选择，浮动操作消失。首页实体卡片再次点击也退出选择。
- 编辑页顶栏显示系统分享 Symbol，并沿用 HDS 顶栏材质；画布菜单中分享 Symbol 跟在每个 pill 后，目标触摸区独立。画布弹出菜单立即关闭后打开分享会被系统取消；延至退出后打开，复测可见“画布作品”菜单。
- 从画布入口导出可编辑作品包，成功进入真正的系统分享面板，预览标题“可编辑画布”、导入说明和“另存为”等系统动作出现；未选择接收方或向外发送。编辑页分享入口也成功打开“卡片作品”选项。
- 照片上能力显示无描边的半透明阅读衬底，前景文字独立渲染。对天气能力做一次拖动，文字坐标发生变化；撤销后文字坐标与原值一致，撤销按钮恢复禁用。拖动测试已撤销。一次额外测试创建的空白卡片已删除。
- 日期/天气/倒数/电量/URL 的紧凑内容区预算和字号同步调整。透明洞保护、L形轮廓下臂自由定位、叠层不自动搬走、玻璃色最坏背景4.5:1对比度由真实模型测试验证。原生缩放手柄的极小尺寸与连续高频拖动仍需覆盖更多设备和形状。
- 未测浅色、竖屏及API24真机。API24测试确认不导入新材质模块、不调用新材质方法；API26模块动态加载在真机完成启动复测。桌面与图片导出保留确定性的同色半透明衬底，未声称桌面实时玻璃滤镜。
- assembleHap、model、capability-framework、canvas-capabilities、share、layout-perf、editor-perf、git diff --check 通过。5000次热缓存轮廓拖动查询约1.5ms，这是本机模型CPU预算，不是手机/平板FPS，不声称全设备满刷新率。

依据：Huawei [沉浸光感开启方式](https://developer.huawei.com/consumer/cn/doc/HarmonyOS-Guides/arkts-immersive-light-sense-enable)、[API26沉浸材质](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-arkui-nativemodule-arkui-immersivematerial)，以及本机ArkUI/HDS SDK类型定义。
