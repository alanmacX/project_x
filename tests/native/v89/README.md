# V89：边缘自适应、拖动稳定性和桌面完整状态

本目录记录前一阶段 Mate 80 RS 模拟器 `127.0.0.1:5555` 的验证。后续用户授权真机，桌面回归定位和截图见 ../v90/README.md。

- 样式简化为笔触、挂钩、边缘自适应，电量另外保留专用徽章；旧 Dock 与负空间迁移到新样式。
- 左右侧 / 内外贴合使用完整边缘区段，轮廓预采样 257 行并缓存；每次贴合读取 25 个插值位置。内容宽度独立于轮廓起伏，额外凹凸占用只扩展材质与留白，允许内贴合内容伸出卡片，用户宽度最大可设为卡片宽度的 3 倍。
- 贴合衬底使用原生抗锯齿 Path，避免尺寸变化时清空 Canvas 的空白帧。新样式能力一直位于同一个外层节点，拖动开始不再从裁切层切换节点。文字层与贴合路径有独立内容安全区，触摸框和缩放手柄使用相同真实外框。
- 修复背景元素重复旋转两次；新贴合模式固定能力方向，整卡旋转不受影响。
- 课程表采用紧凑时间 + 名称/地点行，第一条尚未结束的课突出，保留全部当日课程、密集布局、节假日及调课规则。
- Form 的新场景在 animateTo 更新闭包里一次提交完整数据，不再等退出动画完成才提交；背景解码后立即启动淡入，完成回调仅负责旧图清理。失去动画回调不影响最终内容可见性。整个组件使用最高层的透明事件面捕获点击，不再让子层的命中策略决定入口。卡片使用百分比定位，避免测量值在动画中变化时产生额外位移。

## 验证

- 全部 30 个现有测试入口通过，release HAP 构建通过。测试包含 620 组左右/内外接触与内容安全预算、200 次超过卡片宽度的固定内容宽度验证、100 次故意丢弃完成回调的 Form 场景更新。
- 原生 QA 页面检查椭圆与五瓣异形，内外贴合、上下滑动，课程表三行。素材为本地 SVG 几何测试形状，不使用远程照片。QA 页面/素材只留在本目录，正式路由与源文件已恢复。
- 连续 16 次原生往返拖动期间采样 24 张截图；内容区域深色字像素始终存在（5543–5592），未在这些采样中出现文字整层消失。数据见 drag-samples.json，保留三个代表帧。这是离散截图检查，不代表逐帧无闪烁，也不是设备 FPS 测量。
- 桌面 Form 检查包括覆盖安装后的恢复、点击进入绑定画布、定时聚焦状态恢复后更新；原用户 MatePad 的具体截图情况尚未在该设备复测，不宣称真机高刷新率验证。
