# 模板编辑与素材库完整交互

## 1. 界面层级

| 位置 | 普通卡片 | 模板 |
| --- | --- | --- |
| 原画布 | 原来的拖动、缩放、旋转、分组、图层 | 相同画布操作，模板内部保持整张设计 |
| 选中对象的 pill | 删除、编辑 | 删除、铺满/缩回、编辑 |
| 编辑 | 保留原来的精细编辑器 | 聚焦预览 + 外观/色彩/内容；移除“高级布局”及旧模板面板入口 |
| 完成/取消 | 原有行为 | 380ms 进入、340ms 回到原位；完成只写入一次，取消保留作品 |
| 素材 | 图片图层、专辑原有编辑入口接共享素材库 | 景深/相遇/相片日历用照片库；唱片/封面/唱片袋用封面库 |

模板位置调整直接在画布完成。编辑器底部只保留安全区，不再用一个“高级”入口混入另一套设置。模板铺满可以随时从 pill 缩回；保存铺满前的几何，重开后仍能恢复。老作品没有该记录时采用居中的合理尺寸。铺满沿用原画布边框及背景逻辑。

## 2. 素材的使用关系

### 照片

内容 → 照片库 → 选择已有照片/带主体照片，或从系统相册导入 → 回到内容页。

景深照片始终绑定同一份原图和主体，选择抠图分类也不会丢失原图。原图模式覆盖画面；主体模式展示抠图。时间位置、智能选位、文字明暗和复位放在预览下方的内联控制区，调整时照片始终可见。没有主体时显示“提取主体”，提取后直接用于当前草稿并缓存供其他作品复用。更换照片重置构图与色调；取消编辑不改变作品，导入的素材仍保留。

### 专辑

内容 → 封面库（封面优先，可切到照片）→ 选择 → 更新当前专辑及轮换来源 → 返回。非方形照片居中裁成独立的方形封面副本，保留原图。融合背景生成一次并缓存。复用同一封面不会重复占用轮换名额，12 张上限给明确反馈。

模板中的专辑资料和轮换仍复用原来的数据能力，但选择入口统一指向共享素材库。普通专辑保留原来的编辑面板，只接入相同素材选择器。

### 全局素材库

添加 → 素材库：全部、照片、抠图、专辑。照片包含原始照片和示例，专辑是明确的封面素材；照片生成过封面后仍可从照片分类复用原图；抠图是同一素材的可用形式。详情提供原图/主体预览和使用动作；导入、提取失败留在当前层并显示原因。空分类显示对应空态和导入入口。

## 3. 操作状态与视觉检查

- 模板没有第二个旧编辑入口；从画布、图层、添加、外部路由都进入同一编辑器。
- pill 只在模板上增加铺满；随选中对象移动，左右不越过屏幕安全边距；图标与文字表达当前动作。
- 编辑、保存、取消、系统返回、子面板返回遵循同一层级；子面板关闭保持当前页签。
- 相片内容与色调页有明确空态；没有照片不能假装已开启景深；没有主体不能进入空白主体模式。
- 导入和异步处理期间禁止重复提交，结果校验当前卡片与选择目标；离开后不写回草稿。
- 滑动切换设计后，同步可用页签、照片及色调状态；组合保留辅助来源。
- 素材名称截断，长内容在局部滚动；小屏及横屏下预览与操作区保持可达。

实机检查与截图另见 UI-REVIEW.md。

## 4. 单个铺满组件与返回细节

- 每张画布最多一个 `template.fill=true`。主动铺满 B 时，A 恢复 `freePlacement` 中的位置、大小与旋转；内容、ID、图层顺序、分组保留。
- 复制/导入到已有全屏组件的画布，目标原组件保留全屏，新组件缩回普通尺寸。空画布允许接收一个全屏组件。
- 旧作品中有多个全屏标记时保留最上层的一个，其余恢复原尺寸；缺少历史位置的旧作品采用居中普通尺寸，作品不删除。处理在共享读取模型中完成，重复读取结果稳定。
- 一次铺满替换作为一次撤销，两个组件的几何与画布背景一起恢复；撤销不回滚其他组件的实时数据。画布“更多”提供可用的撤销/重做入口，图层列表标出“铺满画布”。
- 景深在共享场景渲染时检查各数字区域的前景覆盖，超过 18% 的保守几何阈值时把时间置前；移动到轻微遮挡位置自动恢复景深，不改写照片构图或旧作品。
- 返回作品库保留点击时的画布位置。缩略图主体仍可见（至少一半面积）时执行 260ms 缩回动画；隐藏页面暂时缺少测量结果时复用相同视口的原位置。
