## 核心流程

- 模板：画布 → 编辑 → 外观/色彩/内容 → 完成或取消 → 动画回到画布。
- 景深：内容 → 照片库 → 复用照片 → 时间位置 → 右上/文字明暗 → 完成；调整时预览持续可见。
- 专辑：内容 → 封面库 → 照片 → 自动生成方形封面和融合背景 → 资料 → 添加封面 → 返回资料。
- 普通图片：原精细编辑器 → 图片图层 → 从素材库选择 → 抠图 → 使用 → 原图片设置 → 完成。
- 现有入场 380ms、退场 340ms 保留；异步完成后只有当前卡片可以接收结果。
