# 风格系列、快捷配置与自由编辑

2026-10-31，设计探索，未接入 App 模板入口。前一组简约模块被用户否定，继续保留为历史实验。

## 看样稿

打开本目录的 `index.html`（通过仓库 HTTP 服务），可切换三种风格、两种尺寸、两组配色、本地/东京时间，进入自由编辑拖动独立卡片，撤销，再导出当前 `.fridge`。每种风格/尺寸保留自己的临时修改。关闭页面后这些临时修改不保留；保存文件可以带走作品。

- **仪表**：暗色密集布局、大数字、圆形电量、清晰的对齐关系；优先扫读。
- **纸本**：暖色底板、票根轮廓、倾斜纸片、日程；优先物件与叠放关系。
- **色块拼贴**：蓝橙撞色、横向椭圆与放射形剪纸、错位布局；优先轮廓与节奏。

`canvases/` 有 6 个独立可导入作品。2×2 重新安排并减少信息，不直接缩小 4×4。当前先验证两种方形尺寸，2×4 要另做横向构图。时间、日期、日程、电量、进度全部保留原生能力。票根与放射形是原创 SVG 栅格化的 PNG；轮廓由生产 alpha tracer 提取。没有 AI 图片或 Apple 图像素材。

## 产品方案：作品从模板开始，继续按普通画布编辑

### 不想创作的用户

选风格 → 选尺寸 → 改配色/主内容 → 添加。先给完成度高的成品，默认设置可直接使用。只有日程、课程等依赖用户数据的位置才显示相应选择入口。图库按风格系列浏览，同一系列再看用途与尺寸；不要把十几种 capability 的空白卡片直接当模板商城。

每个系列有自己的视觉语法：字体层级、轮廓、位置、疏密、配色、可用内容。仪表系列可有多个小数据位，纸本可以让照片、便签承担主要画面。精细图文、照片、复古、玩具、东方排印可以后续独立扩展；不用同一布局换六个名字。

### 想修改的用户

快捷设置和自由编辑共同修改**同一份普通画布**。没有模板模式/创作模式的文档复制，也不烘焙为大图。

- 主位置与辅助位置绑定稳定 card ID。切换主内容只改变这一张卡的能力；拖动、旋转和其他卡片保持。
- 快捷设置只写自己负责的属性。配色更新纸张/墨色映射，保留位置、照片、文字和私人数据。角色被删除后，该快捷入口消失，不偷偷重建卡片。
- 主位置只展示能放下的能力。时间与世界时间可互换；课程表需要单独的大位置和对应版式，不能把课程硬塞进电量小圆圈。
- 自由编辑后仍保留能正常工作的快捷项。用户自己改过的某个色彩退出系列配色映射，配色变化不重置它。
- “恢复布局”作为独立可撤销操作，只恢复布局；用户课程、照片、目标日期继续保留。
- 模板版本更新只作用于新建作品。已添加的作品不随资源包更新被覆盖。
- 自由作品可保存为个人模板；公开分享继续使用原来的设计导出清洗，不带私人日程、课表、令牌和内容缓存。

### 实现边界

系列 recipe 保存样稿版本、各尺寸文件、配色映射、角色/卡片 ID、允许的能力组合。创建时将角色映射到导入后新 ID，私有元数据放本机目录的独立版本化字段；不往 `.fridge` v1 临时塞入未知模板协议。模板更新、分享导入和普通画布编辑沿用事务/恢复机制。

本网页验证了切换配色后保留拖动位置、按尺寸保留草稿、撤销与导出。它还没有做 App 内角色持久化、删除角色或课程大位置配置。更换风格在这里会打开该系列的独立草稿；正式产品优先作为新建入口，已有作品换系列要做可预览、可撤销的数据角色迁移。

## 验证

`node build.cjs` 生成作品；`node capture.cjs` 用生产纯模型 + 当前浏览器适配器渲染。4×4 检查 300/420px；2×2 检查 180/300px；每个尺寸覆盖演示/空/长内容。逐文件执行 package-check 与 cutout-check，另存校验、哈希和渲染 receipt。

`node verify-prototype.cjs` 检查交互、拖动后配色保位、撤销、导出读取及窄屏。最终视觉复查见 `.qa.json`。没有改 App 运行代码或用户作品，没有原生 Form 验收声明。
