# 原型 05：普通冰箱贴与模板共用创作流程

## 1. 当前割裂来自哪里

1. 原型 04 的模板围绕预览自定，普通创作仍是左画布、右表单，手机端还要在画布与设置之间滚动。
2. 从模板进入自由创作时，原流程会另建副本、改名、缩小模板并换底色。用户刚完成的作品因此变了样，也产生新的保存对象。
3. 普通作品同时展示名称、底色、图层、文字、旋转、删除与两种保存按钮。选中对象与操作范围不够清楚。
4. 作品列表用「自由作品 / 模板作品」继续强调创作来源。用户真正需要区分的是哪一件作品、有哪些贴纸、放在哪些桌面位置。

## 2. 统一产品模型

**作品 → 贴纸 → 内容。** 作品承载画布与桌面绑定；贴纸可以来自照片、文字、时钟或模板；内容是这张贴纸里的文字、照片、课程等。

模板负责提供一个完成度较高的起点。选择模板后可以直接自定，也可以进入这件作品的排布，继续加其他贴纸。普通创作可以随时添加一个模板，并继续编辑模板里的来源。

整张作品与单张贴纸分别保留清楚的操作范围：

| 所在位置 | 看到什么 | 做什么 | 完成后 |
| --- | --- | --- | --- |
| 整张作品 | 完整桌面画布 | 添加、选择、移动、缩放、旋转、背景、排列 | 保存这件作品，更新原绑定 |
| 一张贴纸的自定页 | 大预览 + 当前编辑项 | 外观、颜色、点按内容 | 回到原作品的同一位置 |
| 一个内容输入层 | 该对象的少量字段 | 改字、选素材、改日期或课程 | 回到同一张贴纸 |

底部操作和页签按实际对象出现。系统时钟没有虚假的内容设置；组合内部的日期、时钟等保持组合结构。一体式组合在作品中仍然只占一张贴纸。

## 3. 普通用户最常用的操作

- 点贴纸选中；拖动即可摆放，靠近画布中心时出现对齐线并吸附。
- 选中后显示缩放、旋转手柄；底部保留「自定」「排列」「更多」。
- 点空白取消选择。被遮住的贴纸通过右上「选择贴纸」找到，列表按前后顺序显示实际缩略图。
- 添加文字时直接输入；双击已有文字直接进入文字输入。输入层保留字号和对齐，取消输入不改原内容。
- 选中后点「自定」，普通文字、照片和模板共用相同的大预览及外观 / 颜色 / 内容规则。普通照片更换素材时保留对象尺寸、位置与旋转。
- 新加入的贴纸按当前方形、竖版或横向画布自动取合适尺寸并居中。原来的贴纸保持原排版。
- 复制、删除放进更多；删除可以撤销。前后顺序、居中、摆正和步进调整在排列中。
- 作品名称放到标题点击处。保存集中在顶部「完成」；首次保存后接原来的桌面添加流程。

## 4. 模板与普通创作之间的连续性

- 模板自定页的更多中提供「排布与添加」，保留作品 ID、名称、原画布背景、模板位置和大小、桌面绑定。
- 在作品里添加模板，直接使用同一份 44 项目录。选中这个模板后可以继续修改颜色和内部内容，回到作品仍是原来的整张卡片。
- 同类模板换样式继续保留数据。进入单张贴纸编辑时只做临时的居中放大预览，确认写回时恢复原有几何和分组字段。
- 单张贴纸里的数次修改，在作品层合并成一次可撤销操作。取消自定返回原作品。
- 编辑单张贴纸时刷新，恢复草稿包含整件作品及其他贴纸，不能只保存当前放大的孤立对象。
- 作品列表改为显示贴纸数量和桌面位置。「多张贴纸」用于筛选多对象作品，创作来源不承担作品分类。

## 5. 对原生代码的落点

- `Index.ets` 已有 `selectedActionAnchor` / `selectedGroup` / `openEditor`，可以保留选中与手势模型，把常驻设置切换为同一聚焦编辑容器。
- `EditorLayerControls.ets` 原有拖动、缩放、旋转手柄继续负责几何；`EditorVisualChoices.ets` 继续绘制真实外观选项。
- `Index.ets` 的 `layerEntry`、`chooseLayer` 和 `CapabilitySettings` / `AlbumSettings` / `TemplateSettings` 提供内容编辑能力，入口归到选中内容之后。
- 原生卡片可以有多个图片、文字、形状和数据层，发布实现应继续保留这些层的独立位置、已有分组和高级编辑入口。低频层级操作进入选择列表，常用操作留在预览附近。
- 作品、card、capability、groupId、系统绑定沿用原身份。是否从模板开始只决定初始结构，后续追加创作继续写回同一作品。

## 6. 此次可交互范围

已经在同一个 Demo 中接通作品排布、手柄、对齐吸附、普通贴纸的三项自定、文字快捷编辑、共享素材库、44 个模板的插入和再编辑、模板进入原作品排布、整件草稿恢复、撤销和保存。使用生产 renderer 展示内容；相关文件是 `app.js`、`face-editor.css` 和 `board-model.js`。

# 原型 04：原图铺满、背景调色、全模板统一编辑

## 照片

- 原图进入 cover；每次缩放、拖动、换尺寸之后，把相机限制在能覆盖画布的范围。通过共享 `photoControlRegion` 读取画布原点，处理生产模型的小数原点偏移。
- 原图构图只保留「更换照片」「重置构图」和缩放。主体模式保留完整显示 / 铺满；两种模式各自存储构图。
- 背景页提供原色、暖调、冷蓝、玫瑰、黑白。按关联透明主体的 alpha 保护前景；羽化边缘插值，保持原图透明度。
- 颜色处理输出临时背景缓存，最多 6 项；原始素材字节与共享排版不变。作品只存 `photoTone`，重开时本地生成。原图和前景继续使用同一生产相机。
- 自动时间选位保留原图铺满；只在主体模式允许缩小主体让出时间。

## 其他模板

- 模板目录从生产 `CARD_TEMPLATES` 读取全部 44 项，按用途筛选。
- 同类样式在外观页切换，保留 capability、素材、卡片 ID、作品 ID 和绑定。组合的不同用途保持各自结构；方形 / 横向是次级选择。
- 自动时钟、日期、日历、农历、进度和电量只显示外观与颜色。可配置内容才显示内容页。
- 专辑点封面复用素材库、点文字改标题。课表点预览进入课程列表，课程字段只在选中后展开；学期、周次和单双周收在 disclosure。日程支持名称、地点、时间和全天。
- 倒数日、纪念日直接改名称与日期；世界时钟选城市及其 IANA 时区。
- 组合辅助内容的点按框使用生产 `compositionLayout`；相片日历的照片框使用生产 `photoControlRegion`。编辑来源写回原来的 primary capability / template.sources。
- 关闭输入层不应用；完成输入后作为一次可撤销修改。时间非法时留在输入层；作品退出时保留保存 / 放弃选择。

# 原型 03 更新：模板围绕预览编辑

这次撤掉模板中的常驻表单和左右设置栏。模板详情变成横滑选择页，编辑变成固定的大预览与单项控件。

- 进入编辑：点「自定」或长按模板。外观 / 颜色 / 内容可横滑，也可直接点选。
- 点选内容：在画面里点照片、时间、课程、封面或文字；编辑范围与点中的对象一致。
- 输入文字：浮层只显示该对象字段；点击完成应用一次修改，关闭不改变草稿。
- 景深：点照片才显示构图控制；点时间才显示六个位置与字色；原图和主体各自记住构图。
- 保存：顶部只有「完成」。新作品完成后进入桌面添加，已有作品更新原记录。作品名称、画布尺寸、自由画布放进更多选项。
- 未修改直接返回；修改后可保存、继续或放弃。原来的作品、素材、归档、绑定继续使用原有原型数据结构。

实现文件为 app.js / face-editor.css。旧的 standardCustomize 与 depthEditor 表单实现已移除。下文保留第 2 版对原生调用点与素材管理的分析；其中编辑器视觉结构以本节为准。

# 本地创作、素材复用与景深编辑

2026-11-09 · 第 2 版原型。按用户反馈，产品以本地作品和素材为中心，移除每周推荐、内容运营首页与营销横幅。

## 1. 一级入口：作品 / 素材库 / 模板

| 入口 | 用户来这里做什么 | 主要动作 |
| --- | --- | --- |
| 作品（默认） | 继续编辑、找到已在桌面的作品 | 编辑、新建、副本、管理桌面位置 |
| 素材库 | 保存以后会重复使用的照片、透明主体、专辑、背景 | 导入、筛选、分组、收藏、查看使用关系、创作 |
| 模板 | 为新作品选择现成的结构 | 按用途选款，接自己的素材 |

新建只呈现三个选择：景深照片、从模板开始、自由画布。模板和素材共同服务一件作品，不另建收藏夹、推荐流或内容账号。已有自由画布按原来的排版进入编辑。

素材库可以独立整理；创作中打开的是同一个库的选择面板。用户不需要退出作品再去找文件，也不需要为每张作品重复导入和抠图。

## 2. 当前代码里值得直接调整的地方

### 照片入口分散

`entry/src/main/ets/views/TemplateSettings.ets:35` 的更换照片、`:37` 的提取主体、`:39` 的调整照片与时间是分开的动作。原型把选图统一接到素材库，已有关联主体的素材直接带入编辑。新图的原生主体提取可沿用现有任务，结果登记到素材记录。

### 切换照片模式会复位

`entry/src/main/ets/views/TemplatePhotoEditor.ets:57` 的 `change('mode')` 同时重设 zoom、offsetX、offsetY 和 framing。用户来回比较原图、主体时会丢掉刚才的构图。

原型分别保存两种模式的相机位置。切回原图或主体会恢复各自的缩放与位移，复位成为显式操作。

### 自动选位的能力边界

`TemplatePhotoEditor.ets:65` 复用 `recommendPhotoClock` 选择位置与颜色。大主体铺满时，六个候选位置仍可能被遮住。

原型的「自动排好」先使用原来的 alpha / 明度评分；遮挡仍高时，尝试完整画幅与更小的照片，再选位置。相机和时间位置一起构成一次撤销。这是由用户触发的排版，不在拖动过程中不断抢走时间位置。

### 专辑素材被收在卡片里面

`entry/src/main/ets/views/AlbumSettings.ets:30` 导入封面后，在 `:44` 写入当前 capability 的 albumItems。原型把封面、名称和音乐人提升为可复用素材；创建专辑卡片时带入一份内容快照。修改库内名称不会悄悄修改旧作品。

原生的定时轮换继续属于作品的行为设置，素材库负责选择和排序封面。用户收藏一张封面后可以在不同作品里采用不同的排版与轮换频率。

## 3. 景深编辑如何组织

### 一张固定画布，三个编辑对象

- **照片**：当前素材、更换、原图 / 主体、主体遮挡时间、缩放、完整显示 / 铺满 / 复位。
- **时间**：直接点时间进入；可拖到六个位置并吸附，也可点位置按钮；选择文字颜色或自动排好。
- **底色**：四套配色、选择背景素材、移除背景素材。

手机上顶栏、预览、编辑区都在同一屏内，控制区独立滚动；大屏并排。照片使用生产共享渲染器，拖动与双指缩放复用 `PhotoCameraGesture` 和同一相机坐标。

### 让操作结果可见

- 点时间就在画布上选中时间，不必在一串设置里寻找位置选项。
- 「按住对比」临时把时间放到主体前，松手恢复，不改作品状态。
- 切换模式、换素材、自动排版、拖动、缩放、颜色都可撤销。
- 放弃编辑恢复原作品；保存后才更新作品和已有桌面位置。
- 未完成的编辑单独保存为恢复草稿，作品页显示继续入口，不增加空作品。

### 原图与主体必须对齐

原型包含一组真正对应的原图和透明主体。用户也能导入自己的原图，再关联保留原画幅的透明 PNG / WebP。普通不透明照片显示完整照片模式，未关联主体时景深开关不可用。

原生落地时，主体提取阶段应把原图尺寸、透明主体、crop 映射和提取版本存为同一素材的派生关系。透明主体可以独立复用；原图景深始终使用同一套缩放与位移。

## 4. 素材库的行为

| 情况 | 原型里的处理 |
| --- | --- |
| 多选文件导入 | 按类型导入，显示真实处理状态；本地生成预览 |
| 相同文件再次导入 | 比较 SHA-256，复用原来的素材记录 |
| 原图已有抠图 | 同一条素材记录，详情可切换原图 / 主体 |
| 想重复使用 | 从详情直接创作，或在编辑页选择素材 |
| 素材越来越多 | 类型、分组、名称搜索、收藏、排序；批量移到分组 |
| 改素材名称 / 专辑元数据 | 修改素材信息，旧作品的文字和排版保留 |
| 不想在库里继续看到 | 归档，仍保留被作品使用的内容；可恢复 |
| 看不出图片用在哪里 | 详情列出引用它的作品，直接进入编辑 |
| 自由画布增加照片 | 从同一素材选择器添加，原来的图层和位置保留 |

## 5. 原生实现时的优先级

### P0：把这三段流程接顺

1. 作品为默认入口；已有作品直接编辑。把模板选择限定为新建或显式换模板。
2. 素材选择器统一接入普通照片、主体、背景和专辑封面；第一次导入就登记，提取结果复用。
3. 景深页保留固定预览；支持模式构图记忆、直接操作时间、清楚的遮挡开关、一次操作一次撤销。
4. 编辑用独立草稿，退出时明确保存 / 放弃；后台或异常退出后能继续。

### P1：减少重复劳动与意外影响

- 素材按内容标识存文件，作品持有稳定引用；缩略图和 alpha 分析结果按素材版本缓存。
- 从旧作品扫描图片与封面，先补素材索引，保留 canvasId、cardId、groupId 和桌面绑定；不要重新建作品来完成迁移。
- 归档与文件清理分开。文件清理检查作品、草稿、备份和派生素材引用。
- 选取封面时先看到完整原图和预览裁切，保留可重调原图；不要在导入时直接丢掉边缘。
- 素材改名与作品中的标题分开。需要批量同步时单独给明确动作和影响列表。
- 避免每次拖动读取文件、重新解码或重新分析主体。相机反馈走轻量重绘，手势结束再落盘。

### P2：在现有能力上继续打磨

- 专辑轮换在作品内显示下一张预览和当前顺序，顺序编辑复用素材选择器。
- 提取主体失败时保留原图和任务入口，允许换图或导入透明版本。
- 从桌面点击作品时直接打开对应作品，返回路径保留当前编辑上下文。
