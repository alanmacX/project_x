# 花形色片试作

2026-11-01。按用户要求，将上一版圆角矩形色片围绕表心旋转，形成花状的时钟盘面。

- 三条 / 四条 / 六条单色矩形分别以 60° / 45° / 30° 错角叠放。每条的几何中心与表心重合，两端都露出；色片本体不使用渐变。
- 复用现有调色盘的共享时间模型和指针，不在盘面添加文字、数字或日期。
- 旋转滑条、预览时间，以及浏览器内的缓慢旋转/暂停；尊重减少动态效果设置。
- 仅为独立设计试作，未替换图库中的调色盘，也没有修改正式 App 或承诺桌面持续动画。
- 全部为 DOM/CSS/SVG，未新增图片素材。

`node verify.cjs` 验证色片数、无字盘面、旋转、时间、播放/暂停和 390px 布局；输出 `overview.png` 与 `mobile.png`。
