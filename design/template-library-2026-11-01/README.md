## 数据与组合

`fixtures.js` 保存独立的示例数据；没有查询个人日程、课表、电量或网络。固定时间 2026-11-01 09:41 +08:00；日程/课程是明确的虚构演示。

`renderers.js` 使用生产纯模型 CapabilityCalendar、TimeCapabilities、CapabilityData、TimetableLayout 计算日期、跨日、时区、农历、进度、课程。数字保持 DOM/SVG 文本，未烘焙到图片。

组合 manifest 有独立 sources 列表；这次 browser study 将它们渲染在同一视觉表面。原生集成继续通过多张 card 的组合/配方实现，每张保留单 capability，不向原 schema 填入多 capability card。是否需要新的“组合卡”产品抽象，留到组合方案实审，不在本次样稿里偷改数据协议。

## 个性化与呈现

每款在 catalog 声明有意义的定制项。原型已接通配色、适用标题、景深、放置方式与背景/画框；完整换个人照片、时区、数据源等控件沿用之前原型及正式 App 的能力，本图库没有为每项重做完整编辑器。

模版为独立专属 renderer，普通 card 编辑保持不动。场景中所有数据和资源都先准备好再进入显示，设计落地与升级保护按 [融合方案](../card-template-fusion-2026-11-01/ARCHITECTURE.md)执行。
