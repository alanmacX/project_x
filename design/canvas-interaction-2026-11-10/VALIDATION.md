# 画布交互验收 · 2026-11-10

## 交付位置

独立 Harmony demo：`FridgeMemo-HarmonyDemo`，分支 `demo/harmony-canvas`，包名 `com.fridgewidget.demo`。原工程实现文件没有修改。

## 七项修改

1. 点选、直接拖动、长按和图层点选同步当前卡片；pill 按当前卡片显示，普通照片不会再带模板“铺满”。
2. 新增每画布 40 步事务历史；移动、大小、旋转、显隐、增删、复制、图层排序、组合、模板编辑和铺满切换可撤销/重做。选择卡片不会清空画布历史。普通编辑器保留细粒度编辑历史，完成返回画布后作为一个事务。
3. 移动与长按不改 z；层级仅通过面板排序或明确的上移/下移操作修改。
4. 全屏模板按共享渲染投影固定到底层，普通冰箱贴在上方可操作；保留原来的 z/group，铺满期间排除刚体组合变换。一画布最多一个全屏模板。保存铺满前背景，缩回或删除全屏组件时恢复；存储、作品包资产和私有资产枚举支持这份背景。
5. 图层展开后隐藏画布 pill 和变换手柄，操作归属面板；面板为非模态展开区，顶部撤销一按即生效。
6. 铺满使用 SDK `fullscreen`，缩回使用 `square_and_square`；大小调整保留双向箭头。显示选中边界并裁切到画布。
7. 行内保留缩略图、名称、单行类别、可见性和排序手柄；底部固定编辑/铺满/更多。列表独立滚动，底部动作不覆盖最后一行；排序拖到边缘可滚动。展开工具时按画布比例缩小预览，预览与面板不重叠。

## 原生实测

Mate 80 RS，HarmonyOS API 24，1320×2848。临时复制“我的画布”进行操作，完成后删除测试副本。

- 模板选中后直接拖普通照片：pill 切为普通操作；撤销恢复移动。
- 图层面板选中翻页：头部与底部无 pill 覆盖，画布完整位于面板上方。
- 拖排序把翻页移到最上面；面板保持打开，一次点击导航栏撤销，顺序恢复为普通卡片、翻页、浮字、唱片。
- 翻页铺满：原景深模板缩回；翻页缩回恢复背景；连续撤销恢复原全屏组件与层级。
- 画布进入模板编辑、改色、完成返回；换选普通照片后撤销，模板颜色恢复。
- 普通冰箱贴进入原精细编辑，图片→素材库→窗边的猫→抠图→使用→返回编辑→完成返回画布。
- 删除普通卡片后撤销，原卡重新出现在图层列表。
- 返回作品库抓取 14 帧，看到完整画布缩回原作品卡片的中间态；380ms 模板进入与 340ms 退出路径保留。
