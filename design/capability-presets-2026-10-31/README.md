# 单个能力的卡片预设：原生基础稿

2026-10-31。用户明确：预设以**一个 capability 的一张卡片**为单位；用户能使用编辑器从头制作同样的卡片，也能套用后继续修改。整张画布的布局另由用户决定。

这组是原生元素基础稿。用户评价材质粗糙，继续制作 [材质版](../capability-materials-2026-10-31/README.md)；没有将基础稿标为已认可模板。

六张卡：液晶时钟、唱片时钟、信号时钟、日历纸、倒计票、电量吊牌。每个 `.fridge` 都是 `kind:card`、恰好一张卡/一个能力，assets 为空。装饰用原来的矩形/圆形/线条，文件里没有烘焙时间或私人日期。

HTTP 打开本目录可看实际渲染，点击“看做法”开关装饰图层、换纸张与墨色、移动能力，导出当前单卡。四条制作步骤对应真实图层。预览的日期、电量、倒计目标来自独立演示 fixture，不进入导出。

检查：`node build.cjs`、`node capture.cjs`、`node verify.cjs`。预览覆盖 180/300px × 演示/空/长内容，共 36 张；交互检查六张卡的图层开关、配色、位置、还原及真实导入器读取导出文件。记录在各卡 `.qa.json` 和 `gallery-qa.json`；原生 Form 验收为 false。
