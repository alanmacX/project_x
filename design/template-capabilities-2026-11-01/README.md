# 模板能力样稿与卡片配置原型

2026-11-01。用户选择“模板 / 自己创作”作为卡片配置的两条路径；个性模板可替换个人照片并结合抠图。新样稿使用可免费商用的真实素材，不引用旧稿的生成式 AI 材质。

## 看样稿

- 通过仓库的 HTTP 服务打开 `index.html`：双入口配置、三个专属模板的即时预览与个性内容设置。
- `overview.html`：三组、六种样式的对照。实际截图为 `overview.png`。

| 模板 | 样式 | 设置 |
| --- | --- | --- |
| 翻页时钟 | 炭黑 / 暖白 | 12/24 小时制、日期开关、时区 |
| 纸本日期 | 原色纸 / 冷白纸 | 跟随设备日期，月份/星期/月历作为同一构图；小尺寸自动改为本周 |
| 我的照片 | 真实抠图主体 / 整张照片 | 两个授权示例、换自己的主体或照片、背景色、前后层次、大小与左右位置、日期开关 |

模板可以有独立字形、布局与材质，不要求用原编辑器中的几何图形拼出相同外观。画布仍负责卡片的移动、缩放、旋转和排序。

## 两条配置路径

模板页保留每个模板自己的设置，换模板或切到自己创作时不重置。自己创作页在原型中提供能力、形状与配色，并能导出当前 reader 可读的普通单卡；正式接入时使用 App 原来的完整自由编辑器。

“保存方案”下载明确标识为 `fridgememo-template-study` 的设计配置 JSON；这是专属模板的原型格式。它没有伪装成当前 App 可导入的 `.fridge`。自己创作的“导出单卡”则使用现有 v1 `.fridge`，已由真实 reader 校验。

## 个性内容与抠图

浏览器原型可载入本机照片或已有透明背景的抠图，画面立即更新；素材在本机解码、缩小和压缩，不上传到外部服务。没有透明区域的图片作为抠图导入会提示改用照片，保留之前的有效主体。整张照片模式关闭无效的主体深度控件。

App 的接入路径是选择自己的照片 → 调用原来的 `SubjectShape.ets` / CoreVisionKit 抠图 → 将原图和主体分别交给模板 → 调整主体与时间层次。主体图资源和模板外观分开保存；更换模板不丢原照片与抠图结果。该步骤延用原来的本机抠图能力，不另接生成服务。

## 共享数据和专属显示

`templates.js` 读取生产纯模型 `TimeCapabilities.clockOffset/cityReading` 与 `CapabilityCalendar.calendarCells`，相同时间戳驱动三个专属显示；没有将数字烘焙进图片。当前页面按分钟更新，页面隐藏时停止计时器，返回后按实际时间更新。这里没有新的网络数据源。

本目录是独立的浏览器设计原型，没有修改 App 存储协议、native renderer 或 Form。正式新增模板能力时按照前一份架构方案完成共享布局模型、App/Form 适配、配置持久化、导入/恢复兼容和资源引用。

## 素材与开销

照片使用 Wikimedia Commons 的 Painjet / Matt Buck 作品，纸张来自 ambientCG，数字字体为 Barlow Condensed Black。完整作者、授权、派生说明见 [LICENSES.md](LICENSES.md)；哈希、处理和运行文件尺寸见 [sources.json](sources.json)。`sources/` 保留下载原件，`assets/` 保存裁边、缩小和压缩后的运行资源；原型只引用运行资源。

两个默认主体保留真实透明 alpha，纸张为 CC0 扫描素材；字体原文件和完整 OFL 授权随附。用户自行载入的素材与默认来源分别记录；模板配置下载不包含运行时钟快照。

## 验证

`node build-assets.cjs` → `node verify.cjs` → `node capture.cjs`。

检查双入口、各模板独立草稿、时区、12/24 小时制、跨日、主体前后顺序、大小/位置、透明图导入、错误图保留、普通照片导入、设计配置下载、真实 reader 读取自创单卡、390px 窄屏，以及六种样式在 180/300/420px 下的 18 份渲染。纸本小尺寸展示大日期与本周，避免将整月数字压小。详情见 `qa.json` 和 `previews/`。
