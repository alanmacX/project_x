# 画布切换：三个设计原型

2026-10-17。设计探索，使用内置 image_gen；未修改业务代码。提示词完整保存在 `prompts.json`。

共同约束：保留现有白底、单色原生控件、轻浮动工具与贴纸作品视觉；画布缩略图按创作比例呈现。画布切换不再藏在 sheet / popup 内，也不提供桌面绑定设置。打开画布仅切换 App 编辑目标，桌面实例绑定由桌面小组件设置管理。

| 方向 | 浏览与编辑 | 适合场景 | 代价 |
| --- | --- | --- | --- |
| A 作品库首页 | 全屏缩略图作品库 → 点开独立编辑页 → 返回作品库 | 数量多、需要识图找作品、混合规格和管理 | 从编辑切换到另一张需要先返回 |
| B 横滑工作台 | 浏览时左右滑整张画布；点击编辑后锁定当前作品，完成回浏览 | 少量常用画布、强调沉浸与翻阅 | 必须区分浏览/编辑手势；大量作品逐张找较慢 |
| C 常驻缩略图轨道 | 同页保留主画布与横向缩略图，一次点按切换 | 经常在几张作品间对比与修改 | 常驻轨道占编辑高度；作品多时仍需完整总览 |

建议先比较 A 与 C。A 的结构变化最大，能让“画布”成为首页主要内容；C 更接近现有创作首页，切换效率高。B 更适合沉浸浏览，需要明确浏览/编辑模式，不能让横滑翻页和卡片拖动争夺同一手势。

每张图为两个状态：

- A：作品库首页、独立编辑页。
- B：横滑浏览、锁定当前画布编辑。
- C：当前 4×4 作品、切换到 2×4 后仍保持相同轨道与工具位置。

后续无论选择哪种，重命名/复制/分享/删除放到每张作品的更多菜单；新建画布与添加卡片必须使用不同的明确上下文；按系统返回先结束当前编辑再离开页面。没有画布时展示新建入口；作品较多时 A 可加入搜索，C 可加入独立总览页。

这些是生成的概念效果，不是原生端实现截图。最终需按 44vp 触控目标、安全区、系统字号及短屏进行布局验证。
